# 当前手—物处理链

![H2O真实样本处理链](../datasets/H2O/experiments/visualization_archive/legacy_explanations/hand_object_pipeline_k2_4.png)

这不是一个端到端生成模型，而是一个“观测优先、生成兜底”的分层实验系统。它把非刚性的手/臂与刚性的
操作物体分开建模，在目标ego相机中解决运动、外观和遮挡后，再与背景合成。图中使用`subject3/k2/4`
的真实数据；未来ego只出现在最后一格作评测对照。

## 手和手臂：非刚性动态层

1. 四路同步exo首先各自提取手关键点和手臂RGB-D点；多视角结果在世界坐标中融合并做时序降噪。
2. 根据预测ego相机位姿，把三维关节、骨架包络和手臂点投影到目标画面，得到允许接收动态前景的空间范围。
3. 当前时刻exo RGB-D只有同时通过运动检测、深度有效性和骨架邻域门控时，才成为手/臂纹理；远离骨架的
   动点不会因“在动”就被当成手臂。
4. 手是非刚体，因此不把首帧手纹理刚性贴到后续帧。首帧中的手主要用于识别物体锚点上的遮挡污染。
5. 生成视频后再做两类受限修复：mesh邻域只负责授权封闭小孔，前后各两帧的光流一致观测负责验证和提供
   纹理；有符号距离场共识只在原轮廓3.5像素内稳定外边界。二者均不读取未来ego真值，但使用未来的预测帧，
   因而当前实现属于离线短窗处理而非严格因果。

### “手/臂流”中的RGB究竟来自哪里

最终图里的“手/臂流”是稳定后手mask内的最终RGB，并非全都由同一种方法产生：

| 像素类型 | RGB来源 |
|---|---|
| 主体观测像素 | 同一时刻覆盖目标手/臂最多的一路exo RGB-D，经标定投影和z-buffer搬到目标ego相机 |
| 主视角空洞 | 同一时刻其余exo视角的真实RGB-D，只填空洞、不覆盖主视角；需接近三维骨架并通过颜色一致性门控 |
| 亚像素投影裂缝 | 已观测邻域中至少两个像素的局部RGB/深度均值，最多迭代两次 |
| 封闭小孔 | 光流对齐的前后各两帧预测手部纹理中值；至少两帧支持，否则使用局部Navier--Stokes补全 |
| 时序边界新增像素 | 同样优先使用至少两个相邻预测帧的手部纹理中值，缺失时才做局部补全 |
| 边界过渡像素 | 在1.25像素窄带内，将上述手部RGB与对应背景/物体层做alpha混合 |

因此，主体手臂不是ProPainter生成的，也不是ego首帧贴图。ProPainter被动态保护带挡在手/臂之外；ego首帧
只参与背景锚定及物体首帧手遮挡过滤；未来ego真值只用于指标。真正非观测产生的手部RGB仅限投影裂缝、
已授权小孔和极窄边界，而且这些像素在来源上仍可继续拆分审计。

## 物体：刚性动态层

1. 当前上界实验从四路exo的H2O物体姿态标注融合物体世界坐标SE(3)，并使用数据集CAD表面。这一步没有读取
   cam4物体姿态，但仍是标注上界，不是已解决的自动物体跟踪。
2. 物体外观来自ego首帧：把首帧RGB-D中贴近CAD表面的像素变换到物体局部坐标，形成可随物体运动的有色
   表面，而不是以后逐帧贴一张二维图。
3. 手遮挡物体时，首帧这些像素实际属于手，不能绑定到物体。系统联合使用首帧稠密手mask、exo投影手/臂
   范围以及相对CAD表面的深度次序，把疑似手像素删除；被遮住的物体表面保持未知，不用别的纹理冒充。
4. 每一帧把过滤后的物体局部表面按exo物体SE(3)和预测ego相机位姿重新投影，并用z-buffer形成物体深度和
   可见mask。由于姿态、CAD和首帧深度仍有配准误差，当前主结果采用25%置信融合，而不是100%硬贴图。

## 手—物相互作用与最终融合

1. 手mask与物体mask互斥。若手臂实测深度不大于物体深度加1 cm，手在前；否则物体可见。物体层不能覆盖
   更靠近相机的手，手层也不能随意吞掉有物体几何支持的区域。
2. 物体位置由刚体SE(3)层锁定，二维光流不能移动或扩大物体；手部补洞和边界稳定又受到物体两像素保护带
   约束，避免把指缝中的物体填成手。
3. 背景、手/臂、物体拥有互斥的来源mask。ProPainter只处理无观测背景和授权接缝，不能重画已经观测到的
   手或物体。最终后处理若删除误检手边缘，该像素会返回真实的背景或物体来源，而不是继续保留粉色手语义。

## 已证明的部分与尚未解决的部分

- 过滤首帧手污染后，物体区L1在三个场景加权改善15.14%，物体区时序差分改善6.16%，说明“物体局部外观
  + 刚体运动 + 深度遮挡”的接口有效。
- 手部时序补洞在`k2_5/k2_4`修复区L1改善48.78%/74.18%；轮廓稳定又使三个场景的光流对齐边界抖动
  下降14.60%--17.16%。这些提升集中在被授权的小区域，不能解释成完整手生成已经解决。
- 当前最明显的短板是：完全不可见的手背、手指或单路exo遮挡区域没有可靠外观来源；物体姿态仍依赖标注；
  首帧完全遮挡的物体表面仍保持未知；系统只处理几何接触和遮挡次序，还没有学习抓取力、接触点或动力学。

因此最有价值的研究主张不是“用规则拼出一段ego视频”，而是：将手视为受关节状态约束的非刚体观测层，
将物视为受SE(3)约束的刚体记忆层，再把生成模型限制在确实没有观测的信息区。下一步可以分别替换手部生成器
和物体跟踪器，同时保留同一套可审计的几何、遮挡与来源约束。
